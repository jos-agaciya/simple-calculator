# simple-calculator
A fully functional calculator built using HTML, CSS, and JavaScript with keyboard support, real-time calculations, and a clean responsive UI.

## ✨ Features
- Basic arithmetic operations (+, -, ×, ÷)  
- Real-time result display  
- Clear (C) and delete functionality  
- Responsive design  
- Keyboard input support (bonus feature)  

---

## 🛠️ Tech Stack
- HTML  
- CSS  
- JavaScript  

---

## 🚀 How to Run
1. Clone the repository  
2. Open `index.html` in browser  
3. Start calculating
